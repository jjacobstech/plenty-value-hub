================================================================================
                            API ENDPOINTS CREATED
================================================================================

1. POST /api/uploads/product-image
   → Upload single product image (Vendor/Admin)

2. POST /api/uploads/product-gallery
   → Upload multiple product gallery images (Vendor/Admin)

3. POST /api/uploads/profile-image
   → Upload profile images: avatar, logo, banner (Any user)

4. POST /api/uploads/admin-image
   → Upload admin/site images (Admin only)

5. POST /api/uploads/video
   → Upload videos for admin content (Admin only)

6. POST /api/uploads/document
   → Upload documents (Any user)

7. POST /api/uploads/file
   → Generic file upload with type routing (Any user)

================================================================================
                          STORAGE CONFIGURATION
================================================================================

LOCAL FILESYSTEM:
  DRIVE=fs
  → Files stored in: storage/uploads/
  → Access: http://localhost:3000/uploads/...

S3/MINIO:
  DRIVE=s3
  S3_ACCESS_KEY=minioadmin
  S3_SECRET_KEY=minioadmin
  S3_BUCKET=plenty-value-hub
  S3_REGION=us-east-1
  S3_ENDPOINT=http://localhost:9000

    endpoint="/api/uploads/product-image"

    label="Business Logo"
    value={logoUrl}
    onChange={setLogoUrl}
    endpoint="/api/uploads/profile-image"

    required
  />
